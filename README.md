# tiny-stack-vm

An exact interpreter for make.fun's tiny stack ISA in one dependency-free `main.ts`:
wrapping 32-bit arithmetic, a 256-value stack, ten traps with their own exit codes,
and the 1,000,000-step and 65,536-byte output limits — byte-for-byte faithful to the
reference VM.
